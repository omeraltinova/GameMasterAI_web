# GameMaster AI Web

GameMaster AI Web is an AI‑powered storytelling platform that helps players and groups run interactive narrative sessions online. It provides a web interface for creating characters and campaigns, managing sessions, and chatting with an AI narrator that guides the story.

## Highlights

- Interactive narrative sessions with an AI narrator
- Character and campaign management
- Modern, responsive web UI
- Built for solo play or group collaboration

## Tech Stack

- Next.js (App Router)
- TypeScript
- PostgreSQL + Prisma
- TailwindCSS
- Radix UI + Framer Motion

## Repository Layout

- `gamemaster-ai/` — main application source code
- `gamemaster-ai/docs/` — additional documentation
